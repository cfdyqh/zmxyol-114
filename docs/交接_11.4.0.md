## 二、当前结论（一句话）

**离线改造卡在「去乐固后游戏自己 exit(15)」**：能起进程、能起本地服、能改内存里的 URL，但在 `Cocos2dxRenderer_nativeInit` 附近进程主动退出（exit code 15），本地服一个请求都没收到。

## 三、已确认的事实

### 3.1 官方服务器还活着，但拒绝 11.4.0

- `zmol.4399sj.com` → `119.188.48.34`（能 ping 通）。
- 协议没变：`base64(DES-ECB/PKCS5, key="43((zmIp")`。
- GET 回 `{"code":1001,"errorMsg":"此功能尚未开放"}`；
- 手工构造 `checkupdate` POST → `{"code":1001,"errorMsg":"请勿使用破解版进行游戏(1)"}`；
- 客户端自己发 → 弹「更新检查失败, 请勿使用破解版进行游戏(3)」。
- **真机上同样弹 (3)**（用户实测），所以不是模拟器问题，是服务器不认这个客户端 → **只能离线**。

### 3.2 乐固的完整性校验范围（实测）

| 改动 | 结果 |
|---|---|
| 只**新增** `classes2.dex` | ✅ 正常启动 |
| 改 `classes.dex`（哪怕一个字符串） | ❌ `exited cleanly (4)` 循环 |
| 改 `AndroidManifest.xml`（application/provider 名） | ❌ 同上 |
| 改 `lib/armeabi/libgame.so`（连 `.comment` 段都算） | ❌ 同上 |
| 改 `libtersafe2.so` / `libtprt.so` / `__tpinfo.tsa` | ❌ `exited cleanly (2)` |
| 改 `assets/` 里的图片等资源 | ✅ 正常启动 |
| 整个 APK 重签名（内容不变） | ✅ 正常启动 |

> 注意：Zygote 日志的 `Process exited cleanly (N)` 是 **exit(N)**，不是信号 N。

## 四、去乐固包（已能起，但被 exit 15 挡）

配方（`v11/repack.py` + `v11/build.ps1`）：

1. manifest 的 `android:name` 从 `org.yjmobile.zmxy.zmxyApplication`（35 字符）
   等长改成 `org.yjmobile.zmxy.offline.O`（27 字符）→ 跳过乐固初始化；
2. `lib/armeabi/libtersafe2.so` 换成自写 stub（libgame 需要的 8 个 `tp2_*` C 符号
   + `TssSdk` 的 10 个 JNI native）；
3. 加 `classes2.dex`（本地服 `/data 127.0.0.1:8077`、MemPatch 改 URL、FnForce 登录兜底）。

实测效果：

```
Boot.start → LocalServer listening 127.0.0.1:8077
→ mem: patched http<path>
→ HUMMING onCreate/onStart/onResume 全过
→ 然后在 nativeInit 附近 exit(15)
```
`/data/data/<pkg>/files/offline/` 根本没生成 → 本地服没收到任何请求。

## 五、试过但没解决的（按时间顺序）

| # | 尝试 | 结果 |
|---|---|---|
| 1 | 换 Application 跳过乐固 | 进程 1 秒内死（exit 15） |
| 2 | 占位 ContentProvider 抢先执行 | manifest 被校验 → exit(4) |
| 3 | 改 dex 字符串/方法 | exit(4)（乐固在时） |
| 4 | 假 `libtprt.so` | libgame 链接失败（缺 `g_tprt_pfn_array`/`g_tprt_ori_array`） |
| 5 | 补零数组的假 libtprt | NULL 调用 SIGSEGV |
| 6 | 改 `__tpinfo.tsa` | exit(2) |
| 7 | 去乐固 + 原版 TP2 / stub TP2 | 都是 exit(15) → **与 TP2 无关** |
| 8 | 把 libgame 的 `exit/abort/kill/raise` PLT 改成 `return 0` | 退出码变成 25（还有别的终止路径） |
| 9 | GOT 钩子（dl_iterate_phdr + DT_JMPREL） | 只挂到 `raise`，`exit` 不走 JMPREL；全量扫描版本会 SIGSEGV |
| 10 | `open/openat/fopen` GOT 钩子（只挂 libgame） | **一条都没触发** → 退出不是读文件引起的 |
| 11 | strace 跟 `exit_group` | 主线程先 3 次 SIGSEGV（`SEGV_ACCERR addr=0xcb34d9c`），期间 fork 出 `sh/ps/grep` 子进程（对应 `YJMobileCheckHelper.getSelfProcessName`），随后 exit(15) |
| 12 | 把 `getSelfProcessName()` 改成 `return ""`（dex 补丁，保留方法长度） | 仍 exit(15) → 不是这个检查 |
| 13 | 反射调乐固 `TPShellApplication.initialize(...)` 补运行时状态（`TprtBoot`） | 日志里没看到它执行，结果仍 exit(15) —— **这一步没验证到，是当前最近的待办** |

## 六、下一步（按优先级）

### A. 先确认 `TprtBoot` 到底跑没跑（10 分钟）

把调用从 `FnForce` 线程挪到 `Boot.start()` 里**同步**：

```java
try { TprtBoot.init(app); } catch (Throwable t) { Log.i(TAG, "tprt: " + t); }
```

看日志：
- `tprt initialize -> 0` → 乐固状态补齐，看 exit(15) 是否消失；
- `tprt init failed: ...` → 按异常改参数/签名；
- 完全没有 → 说明 classes2.dex 没更新，检查 build.ps1 是否用了旧 dex。

### B. 如果 A 无效：在 native 里精确定位 exit(15)

- 只对 `libsecsdk.so`、`libtprt.so` 做 `exit/_exit/abort` 的 GOT 钩子（**不要扫全量**，会崩），
  钩子里打 `__builtin_return_address(0)` + `dladdr`，拿到 guest 地址；
- 或者直接改这两个库的 PLT 桩（`v11/patch_exit_plt.py` 已写好），
  一次只改一个库，看退出码/行为怎么变，缩小范围。

### C. 备选：保留乐固，改从 assets 注入

`assets/ucgamesdk/modules/cn.uc.gamesdk.loader.apk`（5.6 MB）是 UC SDK 的插件，**assets 不在乐固校验范围**。
先测 UC 是否校验插件签名（改一个字节看还能不能起）；不校验的话，往它的 `classes.dex`
里塞一个静态初始化调用我们的 `Boot`，乐固保持原样（签名伪造继续生效）。

### D. 兜底

找「脱壳/去乐固」的 11.4.0 底包。有底包直接套 `v800` 的离线方案（本地服 + classes2.dex + MemPatch），
把域名换成 `4399sj.com` 即可。

## 九、环境与坑

- 模拟器：`emulator-5554`（LDPlayer9，Android 9 x86_64 + houdini）。
  启动：`<path> launch --index 0`（约 40 秒后 `sys.boot_completed=1`）。
- adb：`<home>/AppData\Local\Android\Sdk\platform-tools\adb.exe`（不在 PATH）。
- NDK clang：`build\ndk\android-ndk-r26d\toolchains\llvm\prebuilt\windows-x86_64\bin\armv7a-linux-androideabi21-clang.cmd`；
  **必须把 `$env:TMP`/`$env:TEMP` 指到工作区内**（`v11\tmp`），否则报 `unable to make temporary file: Permission denied`。
- d8/zipalign/apksigner 用 **build-tools 36.1.0**（旧版会出匿名内部类/zip 问题）。
- jadx：`tools\jadx\bin\jadx.bat`（反编译 app dex 用）。
- 装机偶发 `INSTALL_FAILED_MEDIA_UNAVAILABLE: Failed to restorecon` → 重启模拟器后正常。
- 原版备份：设备 `/data/local/tmp/uc114.apk`；当前设备上装的是 `test-tb.apk`（去乐固试验包）。
