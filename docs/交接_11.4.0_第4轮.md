## 一、报文编解码（最终答案，已用真实报文验证）

```
wire  = b"-=4399=-" + base64( DES-ECB/PKCS5( json ) )
key   = b"1#(z1Rr>"        # 8 字节，从 libgame .bss 偏移 0x1104 捞出来的
```

- 不是 AES、不是 CBC/CFB/CTR —— 就是**单 DES + ECB**。
- 判定过程（可复现）：把客户端上报的 `lib/libtersafe2.so` 权限从 `r-x` chmod 成 `r--`，
  重新抓包对比：**只有 1 个 8 字节块（第 107 块，偏移 856..863）变化，之后全部不变**
  → 分组长度 8、无链式传播 → ECB。
- key 的来源：libgame 的 `.bss`（运行时 `0x50a3020` 起，key 在 +0x1104）。
  用 `v11/_brute_data.py` 对 .data/.bss 的每个 4 字节对齐窗口做「解密 ct[0:8] 看是不是 JSON」
  扫出来的：`b'1#(z1Rr>'` → `{"ip":"1`。
- 实现：`v11/codec.py`（`decode`/`encode`，一行命令就能加解密）。

## 二、应答格式（v8 的约定在 11.4.0 依然成立）

基础信封是 `{"code":1000,"servicetime":<unix 秒>}`（**不是 0**），按 action 追加字段。
checkupdate 应答：

```json
{"code":1000,"servicetime":1730000000,"resourcepkg":"","datapkg":""}
```

用这个应答，客户端**直接过了更新检查**，进入资源加载 → 登录界面。

## 三、本地服（`v11/mitsrv2.py`）

- 自带 11.4.0 编解码：把请求解成明文（写 `v11/requests.log`），把 JSON 应答加密回去。
- 应答内容用环境变量给：`YJ_RESP='{"checkupdate":{...},"*":{...}}'`。
- 监听 `127.0.0.1:8443`，配合设备上 `adb reverse tcp:8443 tcp:8443`。

### 只重定向游戏服（关键！）

**不能把该 uid 的所有 443 都劫持**：游戏渠道是 **7723（my.7723.com）**，登录是 WebView
加载的网页（`/cysdkfloat/user_9game.php?app_id=1847&...`）。把 SDK 也劫持了，登录页就是空白。
正确做法（`v11/redirect_game_only.py`）：

```sh
iptables -t nat -F OUTPUT; iptables -t mangle -F OUTPUT
# 只把这些 IP 的 443 重定向（= zmol/zmxychatxm/zmxyworldbossxm/zm.4399sj.com）
119.188.48.34 / 222.132.143.16 / 119.188.49.23 / 122.195.144.16
  -> iptables -t mangle -A OUTPUT -p tcp -d <ip> --dport 443 -j MARK --set-xmark 0x0
     iptables -t nat    -A OUTPUT -p tcp -d <ip> --dport 443 -j REDIRECT --to-ports 8443
```

## 四、下一步

1. **登录**：游戏内登录框需要 7723 账号（网页登录 → 回调 → native 发 login 到
   `zmol.4399sj.com`）。有账号就能继续；没有的话下一步是把 7723 的登录接口也吃下来
   （`user_9game.php` 那套，WebView + 回调）。
2. 登录之后的请求（login/选服/role 列表）会出现在 `v11/requests.log`，
   照 v800/v411 的 `LocalServer.java`/`Canned.java` 里的应答样本（`code:1000` +
   角色列表/关卡数据）往 `YJ_RESP` 里加就行。v8 的 `Canned.LOGIN` 里就有一份完整的
   登录应答模板（含 services/rolelist/level 字段）。
3. 注意 `requests.log` 里如果有 `null` / 非 JSON 的请求，说明是 SDK 或 TP2 的接口，
   不要用加密 JSON 回，回空 200 即可。
