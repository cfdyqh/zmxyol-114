## 二、11.4 真灵的正确形状（从客户端里读出来的）

`libgame.so` 0x1c372b0~0x1c373c0 是一串连续的反序列化键，正好是 11.4 真灵对象的字段表：

```
iselite  basepetid  opbasehp  opbasemp  opbasestr  opbasedef
hpimprove  mpimprove  strimprove  defimprove  comprehension  spiritpower  bonelevel
tamestate  triones  petequips  passiveskill  talentskill  mastername
```

再配上 `spiritid` / `globalid` / `level` / `exp` / `skill` / `rare_blood_id`。
**注意 11.4 没有 `sageskillposition`**（那是 13.0 才有的键），多给会被忽略。

`fix259` 就是按这张表重建条目（数值取 `pet.sdb` 的 `*_min` 和 `*_improve_min/max` 中值）：

```json
{"spiritid":9005,"globalid":4399,"basepetid":0,"level":1,"exp":0,"iselite":0,
 "opbasehp":25000,"opbasemp":12000,"opbasestr":4000,"opbasedef":2980,
 "hpimprove":1000,"mpimprove":1000,"strimprove":900,"defimprove":450,
 "comprehension":0,"spiritpower":0,"bonelevel":0,"tamestate":2,
 "triones":[1,1,0,0,0,0,0,0,0],"petequips":[],"skill":[9005000,9005010,9005020,9005030],
 "passiveskill":[],"talentskill":[],"mastername":"","rare_blood_id":0}
```

容器仍是 `savedata.true_spirit_bag = {bagsize:8, maxspiritid:439999, list:[...]}`，
同时下发 `truespiritinfo` / `truespiritlist`（11.4 的内层键名）。
